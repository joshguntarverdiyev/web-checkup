# Security Policy

This edition of Web Checkup contains only Markdown, JSON, YAML and image files. It has no scripts and runs no code of its own.

If you find a problem in the skill's guidance that could lead an assistant to do something unsafe, report it privately with the "Report a vulnerability" button on the Security tab of the main repository, https://github.com/joshguntarverdiyev/web-checkup, rather than opening a public issue.
